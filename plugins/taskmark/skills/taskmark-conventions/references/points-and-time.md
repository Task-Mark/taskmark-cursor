# Points and time (quick ref)

See [sizing](sizing.md) for size ↔ points suggestion rules (no time estimates).

See [effort-time](effort-time.md) for billable minutes, idle auto-cap (next-day 12:00 UTC), and `session_cap_minutes`.

## Defaults (size → points only)

| Size | Points |
|------|--------|
| XS | 1 |
| S | 2 |
| M | 3 |
| L | 5 |
| XL | 8 |

Do not suggest `estimate_minutes` from size or velocity (removed — S-057). Use `0` on create.
