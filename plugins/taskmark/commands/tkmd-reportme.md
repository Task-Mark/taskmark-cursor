---
description: Report what I finished since my last report
---

Use the `tkmd-reportme` skill to collect the work the current git identity
completed since the previous report and write it as human-readable bullets in
`.reports/report-YYYYMMDD.md` on the board, using the board writing language.

This command never commits or pushes. It never edits epic, story, or leaf
markdown. It never writes `CHANGELOG.md` or the board README. It is not run
from `/tkmd-do`.
