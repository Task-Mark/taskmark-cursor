# Commit all projects

Follow the `commit-all` skill. For each linked or discovered git root with changes, create a commit using a **very simple one-liner** message (user-provided shared message, or a short per-repo line derived from the diff / Taskmark item). Do not push unless asked. Then log new SHAs onto the active board item when applicable.
