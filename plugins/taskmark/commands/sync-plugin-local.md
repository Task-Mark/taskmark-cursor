# Sync local plugin install

Follow the `sync-plugin-local` skill. Run `scripts/rsync-plugin-local.sh` from `plugins/taskmark` so `~/.cursor/plugins/local/taskmark` matches this package. Reload the Cursor window if new skills do not appear.
