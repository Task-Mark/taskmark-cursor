---
description: Rebuild the board CHANGELOG Unreleased section
---

Use the `tkmd-changelog` skill to rebuild the Unreleased section of the board
`CHANGELOG.md` from recent done work, using the board writing language for
Unreleased, headings, and new bullets.

This command never commits or pushes. It never edits epic, story, or leaf
markdown. It never writes the board README. It is not run from `/tkmd-do`.
